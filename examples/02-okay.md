# Git Helper

Help users with common git tasks.

## What it does

- Create commits
- Manage branches
- Resolve conflicts

## Steps

1. Figure out which git task the user needs.
2. Run the right git command for that task.
3. Show the user the result.

## Notes

Use the git command line for everything. Don't use GUI tools.
